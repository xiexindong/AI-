# 03 RAG 与微调的区别

> 面试题:**"RAG 和 Fine-tuning(微调)有什么区别?什么时候用哪个?"**

---

## 一、原理

| | RAG | 微调(Fine-tuning) |
|---|---|---|
| 改什么 | **不改模型**,只换检索到的资料 | **改模型的权重** |
| 知识在哪 | 存在外部向量库里 | 融进模型参数里 |
| 本质 | 给 LLM "递小抄" | 给 LLM "补课" |
| 一句话 | 考试时翻书答题 | 考前把书背进脑子里 |

```
RAG:   提问 → 查外部资料 → 连资料带问题给 LLM → 生成
微调:  提问 → 直接进 LLM(知识已在参数里)→ 生成
```

---

## 二、通俗理解(大白话)

```
微调 = 培训员工:公司制度天天学,学到脑子里
RAG  = 配工作手册:不用背,随时翻手册查

微调是"把新知识写进大脑",RAG 是"给大脑配一本外挂手册"。
```

另一个类比(图书馆 vs 背书):

```
微调:让图书管理员把书全背下来 → 成本高、背错难改
RAG: 书放图书馆,他现查现答     → 书更新了,查到的就是新的
```

---

## 三、例子

```
公司新出台制度:「2026 年起年假改为 15 天」

微调方案:
  收集制度语料 → 训练模型(几天到几周、花 GPU 钱)
  → 以后模型默认知道 15 天,但中途再改一次又要重训

RAG 方案:
  把新制度文档切分 → 向量化入库(几分钟)
  → 用户问年假几天 → 检索到新制度 → 答 15 天 ✅
  明天改成 20 天 → 更新文档 → 答案跟着变,模型不动
```

| 对比项 | 微调 | RAG |
|---|---|---|
| 更新新制度 | 重训(贵) | 换文档(便宜) |
| 回答"年假多少天" | 背下来了 | 现场查 |
| 回答"报销流程细节" | 没背过就编 | 查得到就答 |

---

## 四、分析

### 什么时候选 RAG?

1. **知识经常变**(政策、价格、版本)
2. **需要可溯源**(回答要能指到出处)
3. **私有数据不想进训练集**(合规)
4. **预算有限**(微调成本高)

### 什么时候选微调?

1. **改变"行为风格"**(让它像客服、像老师、像医生)
2. **知识相对稳定**(行业通识、固定知识)
3. **需要更低的推理延迟**(不查库,更快)
4. **特定输出格式**(JSON、固定模板)

### 关键认知:两者不是二选一,而是组合拳

```
主流做法:RAG 负责"动态知识",微调负责"人设/格式/领域风格"

  微调让模型"懂规矩"(说人话、格式对)
  RAG 让模型"有料"(答案准确、实时)
```

> 面试话术:"RAG 管**知识准不准**,微调管**说话像不像**。生产上常组合:小模型微调出'领域人设',再挂 RAG 提供实时知识。"

### 对比表(完整版)

| 维度 | RAG | 微调 |
|---|---|---|
| 更新知识 | 秒级,改文档即可 | 天级,要重训 |
| 成本 | 低(检索+API) | 高(GPU 训练) |
| 可解释性 | 强(答案有出处) | 弱(黑盒) |
| 幻觉 | 较少(有材料) | 仍会编 |
| 延迟 | 较高(多检索一步) | 较低 |
| 私有数据 | 不进模型,合规友好 | 进了模型,可能被套出 |
| 技能/风格 | 不改变 | 擅长改变 |
| 适合 | 动态知识、溯源 | 人设、格式、稳定知识 |

---

## 五、优点

**RAG 的优点**(对应微调的缺点):
1. 知识更新零成本(改文档)
2. 答案可溯源,可信度高
3. 数据不进模型,隐私合规
4. 训练门槛低,不用 GPU

**微调的优点**(对应 RAG 的缺点):
1. 无检索环节,延迟低
2. 输出风格可控(人设、语气、格式)
3. 高频问题回答更稳定一致
4. 离线可用,不依赖检索系统

---

## 六、弊端

**RAG 的弊端**:
1. 检索失败就答不好(依赖检索质量)
2. 多一次检索延迟
3. 不会改变模型的行为/风格
4. 知识库要持续维护(切分、权限、版本)

**微调的弊端**:
1. 知识更新要重训,贵且慢
2. 可能"灾难性遗忘"(学会新的忘了旧的)
3. 黑盒,无法解释答案来源
4. 私有数据进模型有泄露风险
5. 训练数据过少会过拟合

---

## 七、面试一句话总结

> "RAG 和微调解决不同的问题:**RAG 管'知识动态准确'**——不改模型,靠外部检索喂材料,便宜、可溯源、更新快;**微调管'行为风格'**——把数据写进参数,改人设、改格式、降延迟。生产上不是二选一,而是**组合**:微调定人设和格式, RAG 供实时知识,前者管'像不像',后者管'准不准'。"
