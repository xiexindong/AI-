# Transformer 知识点

## 一、一句话理解

Transformer = 一个**基于 Self-Attention（自注意力）的序列模型**，让每个 token 同时"看"到序列中所有其他 token，并算出它们之间的相关权重。它是 GPT / BERT / T5 及所有现代大模型的地基。

> 面试一句话版：Transformer 是 2017 年 Google 提出的"注意力就是你所需要的"（Attention Is All You Need）结构，用自注意力机制替代 RNN 的递归，实现了全局建模 + 并行计算，成为大模型时代的底座。

---

## 二、为什么需要 Transformer（RNN 的三大痛点）

在 Transformer 之前，处理序列主要靠 **RNN / LSTM**：

```
用户: "我今天早上在公园看到一只狗，它很可爱"
RNN:  一字一字读 → 读到"它"时，前面"狗"的信息可能已"遗忘"
```

| 痛点 | RNN/LSTM 的问题 | Transformer 的解法 |
|---|---|---|
| **长距离依赖** | 信息要逐字传递，隔远了就"遗忘"（梯度消失） | Self-Attention 让"它"和"狗"直接建立联系 |
| **不能并行** | 必须等前一个词算完才能算下一个 | 所有 token 同时计算，可 GPU 并行 |
| **方向单一** | 从前往后单向传递 | 双向看全文（BERT）/ 双向注意力 |

**核心洞察**：翻译/理解一句话时，一个词的意思往往由"它和其他词的关系"决定，而不需要按顺序一个个地记。直接把所有词两两比较关系，反而更简单、更强大。

```
              ┌─────────────────────────────────┐
              │          输出概率分布              │
              └───────────────▲─────────────────┘
                              │
              ┌─────────────────────────────────┐
              │          Linear + Softmax        │
              └───────────────▲─────────────────┘
                              │
   ┌──────────────────────────┴──────────────────────────┐
   │                      DECODER（解码器）×N              │
   │  ┌───────────────┐   ┌─────────────────┐            │
   │  │  交叉注意力     │◄──│ Encoder 输出      │            │
   │  │ (Cross-Attn)  │   │  (K, V 来自编码器) │            │
   │  └───────▲───────┘   └─────────────────┘            │
   │          │                                           │
   │  ┌───────┴───────┐  ┌──────────────┐                 │
   │  │  掩码自注意力   │  │ 前馈网络 FFN   │                 │
   │  │ (Masked Self- │  │ + 残差+归一化  │                 │
   │  │  Attention)   │  └──────────────┘                 │
   │  └───────▲───────┘                                   │
   │          │ 位置编码 + 输入嵌入                         │
   └──────────┴──────────────────────────────────────────┘

   ┌──────────────────────────┬──────────────────────────┐
   │        ENCODER（编码器）×N                              │
   │  ┌──────────────┐  ┌──────────────┐                   │
   │  │ 多头自注意力   │  │ 前馈网络 FFN   │                   │
   │  │ Multi-Head   │  │ + 残差+归一化  │                   │
   │  │ Self-Attn    │  └──────────────┘                   │
   │  └───────▲───────┘                                   │
   │          │ 位置编码 + 输入嵌入                          │
   └──────────┴──────────────────────────────────────────┘
```

- **Encoder（编码器）**：把输入序列"读懂"，输出一组表示向量。BERT 只用它。
- **Decoder（解码器）**：基于 Encoder 的表示逐 token 生成输出。GPT 只用它（decoder-only，无交叉注意力）。
- 每个 Block = **多头自注意力 → 残差+LayerNorm → 前馈网络 → 残差+LayerNorm**。

## 四、核心组件逐层拆解

### 4.1 Self-Attention（自注意力）⭐ 最重要

**作用**：计算每个 token 和其他所有 token 的"相关程度"，并按相关度融合信息。

三个角色（都由输入向量 X 乘权重矩阵得到）：

```
Q (Query, 查询) = X · W_Q    —— 我要找什么
K (Key,    键)  = X · W_K    —— 我是什么
V (Value,  值)  = X · W_V    —— 我能提供什么信息
```

计算流程：

```
① 算相似度分数:  scores = Q · Kᵀ           (每个 token 两两打分)
② 归一化:        scores = scores / √d_k    (除以维度开方，防止过大)
③ Softmax:       weights = softmax(scores) (变成 0~1 的权重)
④ 加权求和:      output = weights · V      (按权重融合各 token 信息)
```

例子：句子「狗 在 公园 里 跑」

```
「跑」的 Q 与「狗」的 K 算出高分 → 「跑」融合了很多「狗」的信息
→ 模型学到:是"狗"在跑，而不是"公园"在跑
```

### 4.2 为什么除以 √d_k（缩放）

点积随维度增大而方差变大，softmax 容易进入梯度饱和区。除以 √d_k 把方差拉回 1，训练更稳定。

### 4.3 Multi-Head Attention（多头注意力）

把 Q/K/V 各切成 h 份，**并行**做 h 次独立的注意力，再把结果拼接。

```
单头: 只关注一种关系（比如"指代关系"）
多头: 同时关注多种关系
     头1 → 语法关系    头2 → 指代关系    头3 → 语义相似 ...
```

效果：像多个人从不同角度同时审稿，信息更丰富。`d_model=512, h=8` 时每头 64 维。

### 4.4 Positional Encoding（位置编码）

Self-Attention 本身**不感知顺序**——「猫追狗」和「狗追猫」的注意力结果一样。所以要注入位置信息。

```
PositionalEncoding(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PositionalEncoding(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

用 sin/cos 的原因：任意位置的编码都可以表示为其他位置的线性函数，模型能学到"相对距离"。

### 4.5 Feed-Forward Network（前馈网络）

每个 token 独立经过一个两层的 MLP（线性 → ReLU → 线性），做**非线性变换**，增强模型的表达能力。注意力负责"融合信息"，FFN 负责"逐位加工"。

### 4.6 残差连接 + LayerNorm

```
每层输出 = LayerNorm( x + SubLayer(x) )
```

- **残差连接**：解决深层网络梯度消失，让信息直接跳过子层流通。
- **LayerNorm**：对每个样本的所有维度归一化，稳定训练。区别于 BatchNorm（按 batch 维度）。

### 4.7 Masked Self-Attention（掩码注意力）

Decoder 生成第 t 个词时**不能偷看后面的词**（否则就是作弊）。通过 mask 矩阵把未来位置设为 -∞，softmax 后权重为 0。

```
训练时: "我 爱 你" → 生成"爱"时只能看"我"，不能看"你"
```

## 五、Transformer 完整工作流程（翻译示例）

```
输入: "I love you" → 输出: "我爱你"

① 分词 + 词嵌入:  I→[0.1,...]  love→[...]  you→[...]
② 加上位置编码
③ 进 Encoder 6 层:
   - 每层: 多头自注意力(算词间关系) + FFN(加工) + 残差 + LayerNorm
   → 输出 3 个"富含上下文语义"的向量
④ Decoder 逐 token 生成:
   - 输出 "<start>" → 掩码自注意力 → 交叉注意力(参考编码器输出) → FFN
   → 预测第一个词 "我"
   - 把 "我" 拼进输入 → 再生成 "爱" → 再生成 "你" → "<end>"
⑤ 每步输出的 token 概率分布取最高分 → 得到最终译文
```

## 六、Transformer 家族图谱

| 模型 | 用了哪部分 | 干什么 | 代表作 |
|---|---|---|---|
| Encoder-only | 编码器 | 理解（分类/抽取/匹配） | **BERT** |
| Decoder-only | 解码器 | 生成（续写/对话） | **GPT 系列** |
| Encoder-Decoder | 全都要 | 翻译/摘要/转换 | **T5、BART** |
| 多模态 | 全都要 + 视觉编码 | 图文理解/生成 | ViT、CLIP、Sora |

> 我们现在聊的 **GPT = Transformer 的 Decoder-only 版本**：没有 Encoder，也没有交叉注意力，只有"掩码自注意力 + FFN"，反复堆 96 层、上万亿参数，靠"预测下一个词"训练。

## 七、Transformer 在 AI Agent 体系中的位置

```
┌──────────────────────────────────────────┐
│              AI Agent                    │
│  ┌─────────────┐    ┌────────────────┐   │
│  │  规划 Planner│ →  │  执行/工具调用   │   │
│  └──────▲──────┘    └───────┬────────┘   │
│         │                   │            │
│         └─────── 记忆 Memory ┘            │
└──────────────────────────────────────────┘
        ▲           ▲            ▲
        │           │            │
   LLM 大脑 = Transformer
   (Agent 的推理、规划、理解、生成
    全部由 Transformer 完成)
```

- Agent 的**推理能力**（ReAct 的 Thought）由 Transformer 提供
- 工具调用的**参数生成**（JSON 输出）由 Transformer 提供
- 记忆的**向量化**（Embedding）底层也是 Transformer
- **Function Calling / Tool Use 协议**是建立在 Transformer 的指令跟随能力之上的

面试话术：**Transformer 是 Agent 的"大脑硬件"，ReAct/Function Calling 是"运行在其上的软件协议"。**

## 八、复杂度和优缺点

### 复杂度

| 模型 | 时间复杂度 |
|---|---|
| RNN | O(n)（串行） |
| Self-Attention | O(n²)（两两比较） |
| CNN | O(n·k) |

Self-Attention 的 O(n²) 意味着输入越长，计算量平方增长 → 这就是大模型 **context 长度限制**的根本原因（长文本上下文窗口贵）。

### 优点

1. **全局建模**：任意两个位置直接关联，无距离衰减
2. **并行训练**：GPU 可同时算所有 token
3. **可扩展**：堆层数、加维度、加数据 → 涌现能力

### 缺点

1. **O(n²) 注意力**：长序列内存/计算爆炸
2. **训练数据要求高**：没有 RNN 那样的先验顺序假设，需要海量数据
3. **可解释性弱**：注意力权重不完全等于"归因"

### 缓解方案（面试加分）

| 方案 | 思路 | 代表 |
|---|---|---|
| Sparse Attention | 只让相邻/局部 token 互相关注 | Longformer |
| Linear Attention | 把 softmax 换成可分解形式 | Performer、Mamba |
| KV Cache | 推理时缓存历史 K/V，避免重复计算 | 所有 LLM 推理框架 |
| Flash Attention | IO 感知的注意力实现，减少显存读写 | 训练标配 |

## 九、面试要点（背这段）

> **Transformer 是什么**：2017 年 Google 提出，用 Self-Attention 替代 RNN 处理序列，核心是让每个 token 通过 Q/K/V 三矩阵计算与所有其他 token 的相关权重并加权融合，实现全局建模和并行计算。
>
> **核心组件**：
> 1. **Self-Attention**：Q·Kᵀ/√d_k 算相似度 → softmax 归一化 → 加权 V；
> 2. **Multi-Head**：多头并行捕捉多种关系（语法/指代/语义）；
> 3. **位置编码**：sin/cos 注入顺序信息，弥补注意力不感知顺序的缺陷；
> 4. **FFN**：逐 token 非线性加工；**残差 + LayerNorm** 稳定深层训练；
> 5. **Masked Attention**：解码时掩掉未来 token，防止作弊。
>
> **结构**：Encoder 读输入，Decoder 逐 token 生成。BERT 只用 Encoder，GPT 只用 Decoder。
>
> **优缺点**：O(n²) 复杂度换来全局建模 + 并行；长序列是瓶颈，用 Flash Attention / Sparse Attention / KV Cache 缓解。
>
> **和 Agent 的关系**：Transformer 是 Agent 大脑的底座，推理、规划、工具调用、记忆向量化全部依赖它。

## 十、常见追问

**Q1:为什么不用 RNN 了？**
RNN 串行、长距离依赖差（梯度消失）。Transformer 并行 + 全局注意力直接解决，效果全面超越。

**Q2:Self-Attention 和 RNN 谁算得快？**
训练时 Self-Attention 快（可并行，O(n²) 但可矩阵化）；推理时 RNN 单步 O(1)，但 Transformer 有 KV Cache 优化后也不差。

**Q3:为什么用 LayerNorm 不用 BatchNorm？**
BatchNorm 依赖 batch 内统计，序列长度可变时不稳定；LayerNorm 对单个样本归一化，和 batch 无关，更适配 NLP 变长输入。

**Q4:为什么除以 √d_k？**
防止点积过大进入 softmax 饱和区，梯度消失/爆炸，训练不稳定。

**Q5:位置编码为什么用 sin/cos？**
① 可以处理比训练时更长的序列；② 任意位置的编码能表示为其他位置的线性函数，模型可学到相对位置关系；③ 不同频率让不同维度编码不同尺度的位置信息。

**Q6:GPT 为什么没有 Encoder？**
GPT 是 decoder-only：目标是"给定前文预测下一个词"，只需要掩码自注意力，不需要看到完整输入（Encoder 是双向的，会泄露未来）。训练目标（next-token prediction）天然匹配 decoder 结构。

**Q7:context 长度为什么有限？**
Self-Attention 是 O(n²)，序列翻倍，计算量和显存翻 4 倍。所以长上下文要么优化注意力实现（Flash Attention、稀疏注意力），要么花更多算力。

**Q8:多头和单头差多少？**
单头只关注一种关系，多头并行关注语法、指代、语义等多种关系，组合后表征更丰富，效果明显更好。

**Q9:Agent 里为什么总提 Transformer？**
Agent 的 LLM 大脑就是 Transformer；Function Calling 依赖其指令跟随能力；Embedding 记忆也是 Transformer 的输出向量。没有 Transformer 就没有现代 Agent。
